# 班级朗读接力台

由「声线练习室」扩展而来的班级朗读接力应用（纯前端，React + TypeScript + Vite）。

## 玩法与规则

- 课文按句读（。！？；…）拆成**有序片段**，全班按顺序接力朗读。
- 学生只能领取**首个空缺片段**；前一片段未通过时，后续片段不能领取、不能录音。
- 教师**退回重读**时：新录音另存为新版本，原片段及后续接力一并退回待重录，旧版本与旧成绩全部保留不覆盖。
- 同一片段每人只保留**一条有效录音**，历史版本留在档案中可查。
- **取消领取**会释放位置（待教师点评或已通过的录音不可取消）。
- 片段受阻时，界面会显示受阻对象（哪个片段、谁、进行到哪一步）和对应规则。
- 所有数据持久化在 localStorage，刷新/重开后课文、片段、学生、版本与接力顺序保持一致。

## 代码结构（四层分离）

```
src/
  domain/
    types.ts    # 领域模型：课文、片段、学生、领取、录音版本
    relay.ts    # 接力判定：拆段、领取门控、录音版本、点评、退回级联（纯函数）
  data/
    lessons.ts  # 课文资料：原文、拆分片段、朗读提示、班级名单
    store.ts    # 持久化：localStorage 读写、初始数据、重置
  ui/
    StudentView.tsx  # 学生视角：接力顺序、领取/取消、录音、受阻提示
    TeacherView.tsx  # 教师视角：待点评、通过/退回、接力板、版本档案
    useRelayStore.ts # 界面与持久化之间的桥（变更即落盘、失败提示）
    bits.tsx / format.ts
  App.tsx       # 界面壳：角色切换、课文切换、学生身份切换
```

## 运行

```bash
npm install
npm run dev    # 开发
npm run build  # 构建（含 tsc 类型检查）
```

打开后默认学生视角，可在侧栏切换教师视角、课文与当前学生身份；「重置演示数据」可恢复初始接力进度。
