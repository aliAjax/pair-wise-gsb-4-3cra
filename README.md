# 班级朗读接力台

由声线练习室扩展而来的班级朗读接力工具（React + Vite，纯前端）。

## 玩法

- 课文被拆成**有序片段**，学生在接力轨道上按顺序领取、录音、由教师审核。
- 学生**只能领取首个空缺片段**；前一片段未通过审核时，后续片段不能录音。
- 教师**退回重读**时：新录音另存为新版本，原片段及后续接力的有效录音一并退回待重录，旧版本与成绩保留不覆盖。
- 同一片段每人只保留**一条有效录音**（取最高版本）；取消领取即释放位置。
- 所有领取、录音版本与接力顺序持久化在 localStorage，刷新后状态一致；受阻操作会提示对应对象与规则。

## 分层

| 文件 | 职责 |
| --- | --- |
| `src/data/lessons.ts` | 课文资料：课文、有序片段、学生名单 |
| `src/relay/engine.ts` | 接力判定：领取/录音/审核/退回等全部规则（纯函数） |
| `src/store/persistence.ts` | 持久化：localStorage 读写与一致性校验 |
| `src/App.tsx` / `src/styles.css` | 界面：接力轨道、录音台、审核队列、版本记录 |

## 运行

```bash
npm install
npm run dev
```
